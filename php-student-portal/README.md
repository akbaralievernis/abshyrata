# PHP + MySQL Student Portal (MVP)

Минимальная база для перевода текущего проекта на PHP + MySQL.

## Что реализовано
- Регистрация студента
- Вход/выход
- Сессии и защита приватных страниц
- Личный кабинет
- Список студентов
- SQL-схема для MySQL

## Быстрый запуск
1. Создайте БД и таблицы:
   ```sql
   SOURCE schema.sql;
   ```
2. Обновите параметры в `config.php`.
3. Запустите встроенный сервер PHP:
   ```bash
   php -S 0.0.0.0:8080 -t .
   ```
4. Откройте `http://localhost:8080/index.php`.

## Следующие шаги до production
- CSRF-токены во всех формах
- Ограничение попыток входа
- Админ-модуль (новости, мероприятия, модерация профилей)
- Разделы учебных материалов и расписания
- Логирование действий пользователей

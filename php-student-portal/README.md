# PHP + MySQL Student Portal (updated MVP)

Обновлённый MVP под требования студенческого портала:
- Главное меню с информацией о группе
- Регистрация/вход/выход
- Список студентов после входа
- Отдельная страница каждого студента (`student.php?id=...`)
- Кабинет с редактированием профиля, загрузкой аватара/фото, видео и доп.данными
- CSRF, flash-сообщения, единый bootstrap

## Быстрый запуск
1. Создайте БД и таблицы:
   ```sql
   SOURCE schema.sql;
   ```
2. Проверьте настройки в `config.php`.
3. Создайте директорию `uploads/` и дайте права на запись.
4. Запустите сервер:
   ```bash
   php -S 0.0.0.0:8080 -t .
   ```
5. Откройте `http://localhost:8080/index.php`.

## Для существующей БД
Если таблица `student_profiles` уже существует в старом варианте, добавьте поля через `ALTER TABLE` (см. описание миграции в задаче).

# Анализ текущего сайта и план перевода на PHP + MySQL

## 1) Что это за сайт сейчас

Текущий проект — это **портфолио/веб-платформа студенческой группы AUB-1-24** на Next.js 14 с Supabase.

По структуре и коду это:
- Публичный сайт (главная, список студентов, профиль студента, новости, поездки/мероприятия).
- Кабинет студента (`/dashboard`) с редактированием профиля.
- Админ-панель (`/admin`) с формой публикации новостей.
- Источник данных сейчас смешанный: демо-данные в `lib/data.ts` + интеграция с Supabase.

## 2) Сильные стороны текущего решения

- Современный интерфейс и адаптивная верстка.
- Есть разделение ролей: обычный пользователь / студент / администратор.
- Есть SQL-схема и seed для быстрого запуска данных.
- Есть базовая защита маршрутов через middleware.

## 3) Ограничения и проблемы

1. **Зависимость от Next.js + Supabase**
   - Для некоторых учебных лабораторий проще PHP-хостинг + MySQL, без внешнего BaaS.

2. **Смешение демо и прод-логики**
   - Часть страниц берет данные из `lib/data.ts`, что мешает реальной эксплуатации.

3. **Ограниченная функциональность кабинета**
   - Нужны полноценные сценарии для студентов: регистрация, вход, редактирование, просмотр одногруппников, заявки/сообщения, учебные материалы и т.д.

4. **Точка роста по безопасности**
   - Для нового стека важны: `password_hash`, CSRF, валидация, строгие роли, аудит действий.

## 4) Что улучшить до уровня "для студентов"

- Сделать единый портал: регистрация студентов, авторизация, личный кабинет.
- Сделать карточки студентов с управлением приватностью.
- Добавить простую админку: подтверждение студентов, публикация новостей.
- Ввести ролевую модель: `student`, `admin`.
- Подготовить нормализованную MySQL-схему (users, students, posts, events, media).
- Обязательно: журнал ошибок, логирование входов, резервные копии БД.

## 5) План перевода на PHP + MySQL

### Этап 1. База
- Поднять MySQL.
- Создать схему и индексы.
- Настроить PDO-подключение.

### Этап 2. Аутентификация
- Регистрация + вход + выход на PHP-сессиях.
- Хеширование паролей (`password_hash`, `password_verify`).

### Этап 3. Студенческий контур
- Личный кабинет студента.
- Список студентов и карточка профиля.
- Возможность редактирования своего профиля.

### Этап 4. Контент
- Новости и мероприятия из MySQL.
- Публичные страницы для гостей и студентов.

### Этап 5. Администрирование
- Роль admin.
- Управление студентами и публикациями.

### Этап 6. Безопасность и качество
- CSRF-токены для форм.
- Серверная валидация и очистка данных.
- Лимиты на попытки входа.
- Тесты smoke + SQL backup/restore сценарии.

## 6) Что уже изменено в этом репозитории

Добавлен стартовый модуль `php-student-portal/`:
- Регистрация и вход студентов.
- Сессии и защита страниц.
- Дашборд и список студентов.
- SQL-схема под MySQL.

Это не финал, а рабочая база для поэтапного переноса текущего Next.js проекта на PHP + MySQL.
